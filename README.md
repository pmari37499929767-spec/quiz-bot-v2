# Telegram Квиз-бот

Телеграм-бот для проведения квиза по итогам года. Помогает пользователям оценить свои достижения и получить персонализированные рекомендации.

## Описание проекта

Бот проводит интерактивный опрос пользователей:
- Приветствие с двумя кнопками
- Запрос имени с проверкой
- Выбор ниши (инфопродукты, консалтинг, продажи, бизнес)
- Серия вопросов с вариантами ответов
- Подсчет результатов и выдача рекомендаций

## Требования

- Python 3.10+
- python3-venv (для создания виртуального окружения)

На Ubuntu/Debian установить:
```bash
sudo apt install python3.10-venv
```

## Установка и запуск

1. Клонировать репозиторий:
```bash
git clone https://github.com/pmari37499929767-spec/quiz-bot.git
cd quiz-bot
```

2. Создать файл `.env` с токеном бота:
```bash
cp .env.example .env
# Отредактировать .env и добавить BOT_TOKEN=ваш_токен
```

3. Создать виртуальное окружение:
```bash
python3 -m venv venv
```

4. Активировать виртуальное окружение:
```bash
source venv/bin/activate
```

5. Установить зависимости:
```bash
pip install -r requirements.txt
```

6. Запустить бота:
```bash
python main.py
```
